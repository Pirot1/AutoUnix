# GoCourseAuto (GCA) 🚀
Проект по автоматизации прохождения онлайн-курсов с использованием Go и ИИ.

## Технологический стек
* **Язык:** Go (Golang) 1.21+
* **Автоматизация браузера:** [Rod](https://go-rod.github.io/).
* **Интеграция ИИ:** OpenAI API.
* **Парсинг:** Скрейпинг DOM-дерева через CSS-селекторы.

## Структура проекта
* `main.go` — точка входа и основная логика.
* `pkg/browser/` — инициализация и управление браузером.
* `pkg/ai/` — логика взаимодействия с нейросетью.
* `pkg/tasks/` — парсинг вопросов и клики по ответам.

## Как запустить
1. Склонируйте репозиторий: `git clone https://github.com/Pirot1/AutoUnix.git`.
2. Установите зависимости: `go mod tidy`.
3. Создайте файл `.env` и добавьте туда `AI_API_KEY`.
4. Запустите: `go run main.go`.
